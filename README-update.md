# FXツール更新版（mtf-v2）

## 変更内容
- 同じ15分足取得リクエストで最大5000本を取得し、UTCの区切りで1時間足・4時間足を合成します。足の欠けた時間帯・未確定足は使いません。
- 1時間足・4時間足それぞれのSMA5とSMA20が、15分足の売買方向と一致する場合だけ候補にします。
- 既存の90点、RSI、急変動、経済指標回避、重複回避の条件も継続します。勝率80%による通知条件は追加していません。
- 過去検証と定期監視は同じstrategy.jsを使います。過去検証は時点ごとの確定データだけを使用します。
- 新ルール実績を別集計にし、以前のstatsと未決済シグナルは消しません。旧ルール実績は新ルールの勝率に混ぜません。
- 画面を開いた時は保存した結果だけを読みます。ブラウザー閲覧による市場データ取得・通知送信を抑えます。
- 画像分析スコアを勝率として表示する処理を除去しました。

## 勝率の定義と検証の限界
勝率 = TP到達勝ち / (TP勝ち + SL負け + 同一足で両方到達 + 6時間期限切れ)。30件未満は検証中です。過去検証の最後に残った未決済候補は分母に含みません。

過去検証は15分足の確定終値で仮想約定し、その次の足から6時間のTP/SL到達を判定します。実績側は通知候補作成時刻の後に開始した確定足を判定します。足途中の約定経路は分からないため、両方到達を勝ちとして扱いません。期限後のTP/SLは新ルールではカウントしません。

スプレッド・滑り・手数料・過去の経済指標回避・実際の約定価格は未反映です。収益性や将来の勝率を示すものではありません。通知と記録は仮想候補です。実際の口座売買を照合していません。

取得期間はAPIが返す最大5000本の範囲です。必要な上位足が不足すると通知を見送ります。直近確定足が30分超古い場合も通知を見送ります。1時間足・4時間足の不足・不一致によって通知数が減る可能性があります。

## 反映方法
1. ZIPを展開してfx-ai-tool-mainフォルダーを開く。
2. GitHubの同名ファイルを更新し、新規のnetlify/functions/strategy.jsとmarket-status.jsを追加する。README-update.mdも説明として同梱。
3. Netlifyでデプロイ成功を確認する。既存の環境変数とOneSignal設定を使います。
4. 次の定期実行後に画面を更新する。5通貨が順番に表示されます。現状の監視ローテーションは15分に2通貨です。
5. Netlifyのmonitor-marketログでokとtracker保存を確認する。実データのAPI接続・デプロイ・通知配信はこのZIP作成時には未実施。

取得回数は従来と同じですが、返すデータ量と検証計算量が増えます。Netlifyの処理時間・転送量が変わる可能性があります。運用後の利用量を確認してください。
